# SAE 3.03 - Réseau Multi-sites LAN

Étudiant : Ibrahima SOUARE
BUT Réseaux et Télécommunications - Parcours DevCloud
IUT de Colmar - Année 2025-2026

## Présentation du projet

Conception et configuration d'un réseau multi-sites LAN pour deux entreprises fictives dans GNS3. Projet réalisé en groupe de 3 étudiants. J'étais responsable de la partie LAN.

## Ma contribution - Partie LAN

- Architecture hiérarchique 3 niveaux : Coeur, Distribution, Accès
- Plan d'adressage IP complet pour 3 sites avec VLANs 10/20/30/40
- Configuration des switches : VLANs, Trunks 802.1Q, VTP, MSTP
- Routage inter-VLAN Router-on-a-Stick
- Haute disponibilité avec VRRP
- Service DHCP et adressage statique serveurs

## Technologies utilisées

GNS3, VLANs, VRRP, MSTP, 802.1Q, DHCP, Router-on-a-Stick, VTP
